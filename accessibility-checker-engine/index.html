How to Access Your Test Files

To open any HTML test file, use this URL pattern:

http://localhost:5500/test/v2/checker/accessibility/rules/[rule_name]/[file.html]

Example:

http://localhost:5500/test/v2/checker/accessibility/rules/aria_landmark_name_unique_ruleunit/example_0_pass.html

💡 Tips

  • Right-click any HTML file in VS Code Explorer and select "Open with Live Server"
  • The file will open at the correct URL automatically
  • Changes to HTML files will auto-reload in the browser
  • If you get "Cannot GET /", make sure you're accessing the full file path
